# ═══════════════════════════════════════════════════════════════════════════════
# SLIM DEPENDENCY SET — for free / low-resource hosting (Render Free, etc.)
#
# requirements.txt is the canonical, full-feature set.  This file changes NOTHING
# about the application code.  It exists because paddlepaddle + docling exceed the
# image size and build timeout of every free hosting tier (512 MB RAM, multi-GB
# download).
#
# USAGE
#   docker build --build-arg REQUIREMENTS_FILE=requirements-deploy.txt ...
#   pip install -r requirements-deploy.txt
#
# ── What is DROPPED and what degrades ─────────────────────────────────────────
#   paddleocr, paddlepaddle, docling, layoutparser
#     → Scanned/image-only PDF OCR stops working.
#       Both are lazy imports (ocr_orchestrator.py, table_extractor.py) so
#       the app still boots and text-based PDF/DOCX/PPTX ingestion is unaffected.
#       YOU MUST ALSO SET  OCR_SCANNED_ENABLED=false  in the deployment env.
#
#   qdrant-client
#     → Only imported when VECTOR_BACKEND=qdrant. Keep VECTOR_BACKEND=pgvector.
#
#   aioredis
#     → Already removed from requirements.txt (broken on Python 3.11).
#       redis.asyncio from the `redis` package is the correct replacement.
#
# ── What is KEPT and why ──────────────────────────────────────────────────────
#   sentence-transformers / transformers
#     → REQUIRED. reranker_service.LocalCrossEncoder loads CrossEncoder on
#       first query; without it every query raises ImportError.
#       The cross-encoder model (~80 MB) downloads on first use.
#       NOTE: BAAI/bge-m3 (~2.2 GB) will OOM on 512 MB RAM instances.
#       LocalEmbeddingProvider catches that and falls back to
#       GeminiEmbeddingProvider (gemini-embedding-2, output_dimensionality=1024).
#       That fallback is self-consistent on a FRESH database.
#       Do NOT mix it into a corpus already indexed with bge-m3.
#
#   google-genai
#     → REQUIRED by GeminiEmbeddingProvider (gemini-embedding-2 fallback).
#       text-embedding-004 was shut down January 14 2026.
#
#   opentelemetry-* / prometheus-client
#     → REQUIRED at boot. core/telemetry.py imports them at module level.
# ═══════════════════════════════════════════════════════════════════════════════
