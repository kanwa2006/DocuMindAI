# OPTIONAL slim dependency set for free / low-tier hosting.
#
# requirements.txt is the canonical, full-feature set — this file changes NOTHING
# about the application code. It exists because the full set pulls paddlepaddle +
# docling + layoutparser (multi-GB, torch underneath), which exceeds the image
# size and build timeout of every free hosting tier.
#
# USE THIS ONLY IF the full requirements.txt fails to build on your host.
#
# ── What is DROPPED, and exactly what degrades ───────────────────────────────
#   paddleocr, paddlepaddle, docling, layoutparser
#     → Scanned/image-only PDF OCR and the table extractor stop working.
#       Both are LAZY imports (services/ocr_orchestrator.py:17,34 and
#       services/table_extractor.py:25,110), so the app still boots and
#       text-based PDF/DOCX/PPTX ingestion is unaffected.
#       YOU MUST ALSO SET  OCR_SCANNED_ENABLED=false  or scanned uploads will
#       fail loudly at ingestion time instead of falling back quietly.
#
#   qdrant-client
#     → Only imported when VECTOR_BACKEND=qdrant (documents.py:570, lazy).
#       Keep VECTOR_BACKEND=pgvector, which is the default.
#
# ── What is KEPT, and why it cannot be dropped ───────────────────────────────
#   sentence-transformers / transformers
#     → REQUIRED. reranker_service.LocalCrossEncoder.get_model() imports
#       CrossEncoder at first query; without it every query raises ImportError.
#       The cross-encoder model itself (~80MB) downloads on first use.
#       NOTE: BAAI/bge-m3 (~2.2GB) will likely fail to load on a small instance;
#       embedding_service.LocalEmbeddingProvider catches that and falls back to
#       GeminiEmbeddingProvider (768-dim zero-padded to 1024). That fallback is
#       self-consistent on a FRESH database because index-time and query-time
#       embeddings go through the identical path. Do not mix it into a corpus
#       that was already indexed with bge-m3.
#
#   opentelemetry-* / prometheus-client
#     → REQUIRED at boot. core/telemetry.py imports them at module level and
#       main.py imports setup_telemetry at module level, so they load even when
#       OTEL_ENABLED=false and PROMETHEUS_ENABLED=false.
# ═══════════════════════════════════════════════════════════════════════════════
